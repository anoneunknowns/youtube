# 持込資料の原本

このフォルダは未登録の参照画像を原名・元のバイトのまま保全する場所です。[目録](manifest-v1.json) にパス、SHA-256、寸法、形式を記録しています。目録への収録だけで動画の採用素材にはなりません。

目録のパス表記はUnicode NFCに揃えます。macOS等が分解形の名前を返す場合も、同じ可視名・同じ実体を別の原本として重複登録しません。表記を整理するために画像を再保存したり、可視名を付け替えたりしません。

出典、利用条件、用途が不明な場合は不明のまま記録します。採用するときは [画像管理仕様](../docs/IMAGE-ASSET-MANAGEMENT.md) に従って登録し、作品の制作記録から採用先を辿れるようにします。

追加時は原本を保管して目録を更新します。候補・不採用・未登録であることを削除理由にせず、保管と整理は [管理区分](../docs/PROJECT-MAP.md#管理対象を区別する) に従います。
