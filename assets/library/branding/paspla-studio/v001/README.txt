表示範囲の設計
  全デバイスの中央安全域は最小2048×1152時の1235×338という公式値を比例換算。
  2560版で約1544×423となるため、確認用は中央1544×422（x508、y509）を使用。
  チャンネル名、くまの帽子・耳・足、うさぎ、猫、鳥がこの範囲に収まるよう縮小・移動した。
  木、花、ピクニックの周辺小物、道は端末によって切れる背景として配置している。
  ユーザーのYouTube Studioプレビューで問題があった初版はmastersに履歴として保持する。
  アップロードには中央切り出しではなく、exportsの2560×1440画像全体を使用する。

制作と再利用
  描画と構図修正は組み込みimage_genを使用。モデルIDはツールから取得できない。
  FFmpegは書き出しサイズへのリサンプリング・形式変換・確認用切り出しに使用。
  masters/は生成時の無改変画像。書き出し寸法は生成時のネイティブ解像度を意味しない。
  sources/はユーザーの絵柄参照とYouTubeの表示範囲スクリーンショットを無改変で保持。
  generation-record.jsonに参照役割、全プロンプト、履歴、ハッシュ、書き出し条件を記録。
  バナーとアイコンはチャンネル共通素材として再利用可能。サムネイルはカウント動画に適用する。
  数字を含むサムネイルを他テーマに使うときは、内容に合わせて新しい版を作成する。
  背景やキャラが焼き込まれた完成画像なので、個別モーション用の切り出し素材にはしない。
  元のfour-operations / four-operations-commonは変更していない。
