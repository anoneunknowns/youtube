# 動画の基本ポーズと素材QA

通常姿・表情・しぐさは[共通素材ガイド](../../../README.md#動画で使う基本セット)と各IDの `current/asset.json`・`clips.json` から使います。制作時期に関係なく同じ入口です。

この登録は96種類に通常姿の参照別名と9姿勢、7つの離散動作レシピをそろえるものです。採用先は [manifest](manifest.json)、固定原画・採否・観測範囲は [受入記録](qa/acceptance-v001.json)と各登録の `review_evidence` を参照してください。登録は原画・共通尺度・支点・切り出しとSHAを保持します。

PNGは原画の画素を保持した無損失の切り出し、通常姿の別名は採用原画の再利用です。瞬き・挨拶・左右案内・考える・気づく・喜ぶ・固有の2段階のしぐさを収録します。鳥・魚・水生動物などは元の翼や鰭を使います。種のしぐさは小さな尾の返し・翼の開閉・頭や耳の動き等で、連続歩行や飛行を保証しません。

素材QAではネイティブ原画の明暗合成、素材ごとの既存上限での表示、全レシピのデコードした前後姿勢を確認し、不良セルだけ新規生成して再検査しました。生成担当の確認と別担当の審査、再生成前の不合格記録は区別しています。原画枚数・ファイル整合の合格は完成映像の合格とは別です。

最大表示は各通常姿の `resolution_review` と登録の校正を読みます。身体基準高の上限と、可視サイズに対する倍率の上限を混同せず、全員を同じ高さへ拡大しません。足・腹・胴中心など元の支点の意味を保ち、ポーズごとの外接矩形へfitし直しません。

レシピの `durations_ms` は離散プレビューの基本時間で、`loop: false` は一回分です。利用する作品の字幕・教材・音声と合わせて切替順・保持時間・移動・場面接続を設計し、最大表示の原寸、全画面、連続動作と圧縮後の完成MP4で検査してください。不足する中間姿勢は完成原画として追加し、姿勢補間では埋めません。今回の静止／デコード列の審査に、実時間再生・完成MP4の合格は含みません。動画本体・不採用候補・用済み旧版はGitHub公開集合へ追加しません。

生成プロンプト・直接入力の役割とSHA・保存した採用原画は登録から辿れます。過去の候補・大きい診断画像・元ツールの絶対パスは制作原本の履歴で、公開版に同梱される保証ではありません。
