# 現行画像の仕上がり再検査

画像の利用入口は[全素材の共通ガイド](../../../README.md)です。この記録は新旧を分けた素材一覧ではなく、選択された画像のSHAと、今回確認した範囲を残すものです。

120種類・739 PNGを再検査しました。通常姿120点は原寸の主要部位と使用尺度の明暗、その他619点は登録された使用尺度の明暗で確認し、ハリネズミの拡張27姿勢は原寸まで追跡しました。残る592点は使用尺度のscreenであり、全点の原寸合格や完成動画の検査とはしていません。[審査記録](review.json)の各画像の条件を参照してください。

水彩の紙目・柔らかな面・毛並み・種の斑は意図した表現として保ち、汚い色塊・描線の破損・余分な部位は確認されませんでした。判読性は保つものの拡大で輪郭が柔らかくなるハリネズミの `expanded/seated_stretch_half` だけ、元画像を参照して単体の新規原画を2案作りました。

1案目は鮮明ですが線が濃く硬く、2案目はその点を抑えたものの、前後の既存姿勢より線と茶色の面が淡く軽く見えました。独立審査も踏まえ、総合改善が明確でないため、既存版をAIおすすめ・正式版として維持しています。ユーザーのクリックで選ばれたとは記録していません。良好な他の姿勢を候補へ合わせて描き直すこともしません。

正式PNG739枚・採用INDEX・登録・clip・既存作品の入力は変更していません。過去の品質指摘も書き換えていません。新規候補・診断画像・正確な生成条件と比較設定はローカルの担当batchに保管し、公開素材には追加しません。記録内のlocal-only path/SHAは、媒体の公開・同梱を保証しません。
