# 動物キャラと小物の原画・採用記録

素材を使う場合は[全素材の利用案内](../../../README.md)と[共通素材台帳](../../../../../catalogs/asset-library-current-v1.json)から各IDの `current/neutral.png`・`asset.json` を選びます。素材の作成時期で利用入口を分けません。

この記録は、依頼された100件から重複2件を既存素材へ対応付け、特定の難しい2件を見送り、96種類の通常姿を選択した生成・QAの記録です。擬人化キャラ53種類と鳥式の小物43種類を、同じ透過PNG・支点・原画参照の構造で管理します。[選択manifest](manifest.json)と[対応・見送り理由](request-disposition-v001.json)を参照してください。

画風はシャム猫・ハリネズミ・トラの軽い擬人化、またはヤイロチョウの丸い小物表現を基準にしています。ハムスターと黄色い小鳥は例外的な既存デザインです。自然な四足のままだった主役案と、図鑑的に描き込みすぎた小物案を新規描画で修正し、旧QAを現在の合格へ書き換えていません。

各原画は生成出力をバイト一致で保管し、正確なprompt、直接参照の役割・SHA、生成記録、原寸/明暗/最大使用サイズのproducer QAを同じ専用batchへ保存しています。採用はユーザーの制作・管理の委任に基づくAI判断で、ユーザーのクリックとして記録していません。

[全96原画の独立確認](qa/independent-review-v001.json)は現行source SHAへ結合しています。独立確認では想定表示尺度の明暗contactを使い、疑いのあった箇所を原寸で追跡しました。カニの歩脚数、ウミツバメの水かき、細密すぎた小物などを新規原画で修正しています。

通常姿1枚だけの素材に、ポーズや連続動作の合格は付けていません。身体基準・支点・最大表示サイズは各source manifestの記録に従い、場面での補間・動画化・圧縮後の品質は利用時に確認します。学名等は題材の同定と出典の情報で、デフォルメされたキャラ絵を科学的な形態図・現場同定資料として扱いません。属・種群代表、冬羽、幼体、白変種などは該当する素材のtaxonomy注記を参照してください。
