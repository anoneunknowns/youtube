原本・派生・採用範囲
  source/arms-9-source.png は built-in image_gen.imagegen で生成した3×3の9セル原本。
  source/faces-6-source.png は同ツールで生成した3×2の6セル原本。
  合計2シート・15セルの新規生成。15セル全てを独立した本制作採用原画や15種類の演技とは数えない。
  両シートとも通常姿v003を直接の同一性・画風参照として渡した。モデル識別子はツール非公開のため推定しない。
  source/は元生成PNGとbyte一致。RGBAを保持し、色抜き・アルファ清掃・輪郭の膨張収縮をしていない。
  facesのalpha最大254と透明RGBの茶色はそのまま保持し、明暗合成で不必要な背景が出ないことを確認した。
  15セルをframes/へ無損失矩形切出し。正確な元SHA・矩形・出力SHAはprovenance/crop-manifest.json。

  頭、通常の目、顔の輪郭、針、耳、足：採用通常姿v003を保つ。
  動く二つの腕：通常姿v003の局所切出しを、肩と手先の解剖上の基準で連続変形する。
  新規腕シートcell0：元の腕が動いて空く位置の、腕のないクリーム色の肌。

  新規表情シートcell4：驚き・小さな喜びの開いた口。

  事前モックの4キーや、v001・要修正v002を全身切替する方式ではない。goodbyeはgreetと同じ原画・運動の意味ある再利用。

実装と共通登録
  tools/collatz_animation.py の draw_character(image,state,phase,height=260,foot=(960,1030))。
  stateはneutral,greet,even,odd,think,surprise,nod,cheer,stretch,goodbye。
  phase0..1は準備→開く/示す→戻るまでを含む。全状態の0と1は通常姿へbyte一致で戻る。
  通常姿の元身体高1039px・足支点(611,1166)を維持し、作業canvas800×800の共通身体高560px・足(400,740)へ換算。
  原画の身体高や足支点をポーズごとに合わせ直さない。最大表示身体高280px、実動画側の採用尺度はrootのtimeline/rendererを正本とする。
  新規肌の身体高371pxに対する最大倍率0.755、口の幅51pxに対する最大表示27.5px、瞼67pxに対する最大表示27.5px。使用部位を拡大しない。
  腕の肩と手先は連続した角度・長さで補間。全身クロスフェードは使わない。nodは意図した一度の小さな頭の頷きで、足と胴体は保持。
  receiptは可視bbox、登録足、可視下端の足baseline差、使用原画IDと尺度を返す。横方向は登録した解剖上の足支点であり、bbox中央を足支点へ読み替えない。

静止画・画風確認
  previews/source-cells-light-dark-280px.pngで通常姿と新規15セルを、同じ身体高280px・シート共通縮尺で明暗比較。
  使用する局所部位では温かい茶輪郭、クリーム肌、細かい水彩紙目、茶色の目と白目、針のV模様を維持。
  新規全身の目線・頭幅などには小差があるため、全身を通常姿へ置き換えず、採用元の頭・目・足を優先した。
  previews/light-dark-all-states.pngで全10状態の最大姿勢を確認。手と顔の二重像、切断された手、異なる顔へ切替する構成を採用しない。
  身体を固定したまま腕だけが弧を描く、切り絵に近い控えめな演技。指の細かな動作や全身の歩行・着座は今回の演技に含めない。

36秒の原寸動作試作と確認範囲
  previews/motion-demo-1080p30-v001.mp4：1920×1080、30fps、無音、36.0秒・1080フレーム。
  全10状態を各3.6秒、準備から戻りまで描画した。左は通常姿の比較用、中央が演技対象。これはQA用の比較映像で、本編の画面構図ではない。
  FFmpegで全1080フレームをdecode、ffprobeで寸法・fps・フレーム数を確認。
  実MP4から各状態のphase0.15/0.50/0.85の30場面を再decodeし、decoded-motion-contact.pngと原寸代表3枚を画像表示して確認。
  全状態31phaseの足元cropは1つのhashで一致。260px表示時の可視下端は全frameで足支点1030に対し差0px。
  0と1の通常姿への復帰、頷きを除く頭頂の固定をRGBA全channelのbyte比較で確認。
  静止通常姿への置換を負の対照にし、全9非通常状態で画像差が出ることを確認。
  詳細はprovenance/motion-demo-qa.json、motion-demo-receipts.json、geometry-and-effective-resolution.json。
  検査範囲は全decode・連続phaseの自動比較・抽出静止画の目視。人による全36秒再生視聴の記録や、本編の音声・字幕同期の合格とは区別する。
  本編へ組み込んだ後の発話中の動き、動作頻度、長い静止、教材遮蔽、画面切替、完成AAC/字幕との一致はroot側で別に最終確認する。
