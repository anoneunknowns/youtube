# ことりの表示線幅調整 v5

2026-11-03。小さいゲーム画面でくまと比べたときの線幅を改善するため、v4を基に通常姿勢を編集した。旧版は履歴として保持する。

- 方法：built-in `image_gen` の画像編集、`transparent_background=true`。
- 編集対象：`bird-side-outline-v4.png`。`base-v3/bear-beret.png` は茶色の筆致の参照にのみ使用。
- 出力：`bird-side-outline-v5.png`。
- 正確なプロンプト、ハッシュ、alpha・登録値、局所サンプル：[計測記録](bird-side-outline-v5.json)。

元の左向きのシルエット、丸い頭から続く胴体、小さいくちばし、白い光のない茶色の点目、一本の曲線の翼、一つの上向きの尾、二本の足、淡い黄色と紙の質感を保ち、外周・くちばし・翼・足の茶色の線を強めた。頬紅、装飾、別キャラ、影、背景は追加していない。線幅変更に伴う輪郭の広がりは実測し、v4の登録値は流用しない。

## 読み取り計測

同じ茶色判定を使い、頭・頬の左右各5行で外側から最初の不透明な茶色の連続幅を読み取った。曲率、紙の質感、アンチエイリアスの影響を含む水平の局所幅であり、輪郭全周の均一な太さを示す値ではない。

| 画像 | 実際の表示高 | 局所線幅の中央値 |
| --- | ---: | ---: |
| ことり v4 通常姿勢 | 87.5 | 約2.80px |
| ことり v5 通常姿勢 | 87.5 | 約3.93px |
| くま 通常姿勢 | 350 | 約4.62px |

v5は1254×1254、alphaは0〜255、キャンバス外周のalpha最大0。alphaが0.02以上の可視範囲は `[303,325,968,981)`、可視高656、中央・接地anchorは `[635.5,981]`。従来と同じ表示高87.5を保つ縮尺は `87.5 / 656`。

体の相対サイズ0.25は従来の暫定値を維持するもので、新しいサイズ承認を意味しない。
