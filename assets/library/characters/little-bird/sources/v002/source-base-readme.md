## 大きさの記録

[相対サイズ設定](../scale-spec.md) と [機械可読JSON](../scale-spec.json) に、8体の暫定比率と正面・側面・背面への引き継ぎルールを記録しています。画像の余白やキャンバス寸法を、そのままキャラクター間の身長差として使いません。

個別PNGの実寸、透過状態、輪郭の外接矩形、接地基準、基準表示用の等方拡大率は [raster-metrics.json](raster-metrics.json) に記録します。帽子やポーズで基準身長の定義を変えず、縦横比を保って拡大縮小します。

## 模様と原画

猫の茶色い模様は背面で画面左、正面では画面右に対応します。薄い橙色は逆側です。同じ体側の模様として扱います。原画で見えていない正面の顔は、既存キャラクターの顔の描き方に合わせた補完です。

原画を基準としてオリジナルの特徴を維持します。使用した組み込み画像生成の [プロンプト記録](generation-prompts.md) も保存しています。
