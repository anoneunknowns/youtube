Num-Num Numbers — Octal Count
企画・シナリオ案

1. 動画の内容

赤いベレー帽をかぶったピンクのウサギと一緒に、八進数の 0₈ から 177₈ までを順番に数える。ウサギが持つ「DECIMAL」の看板には、同じ数の十進表記 0 から 127 を表示する。数字を聞き取って復唱することと、7 の次に右の桁が 0 に戻り、左の桁が一つ進むことを学習の柱にする。

英語では、表示した各桁を左から順に読む。たとえば 17₈ は “one [0.90秒] seven”、100₈ は “one [0.90秒] zero [0.90秒] zero”。初めの空欄は読み飛ばす。カウント中に十進値を声で重ねず、導入の例と看板で二つの表記を結び付ける。

2. 背景テーマ「Aurora Garden」

フィンランドのラップランド地方、イナリ周辺の風景を参考にした架空の庭を舞台にする。夕暮れの青紫の空に淡い緑と紫のオーロラを広げる。林にはヨーロッパアカマツと山地のカバノキ（mountain birch）を描き、小川沿いにはコケモモなどの低い茂み、苔、灰白色のハナゴケ類、丸みのある石を配する。

左にウサギ、右にクリーム色の数表示を配置する。オーロラは画面上部に見せ、看板や数字の周囲では背景の明るさを抑える。導入からカウントの終わりまで画角を固定し、説明、ストレッチ、締めでは表情やポーズを変える。

3. 共通画面

- 上部にシリーズ名「Num-Num Numbers」と「OCTAL COUNT」、範囲「0–177 IN BASE 8」を表示する。
- パネル内に 3 桁を固定幅で配置する。上に「BASE 8」、桁の下に右から 1、8、64 の重みと「PLACE VALUE」を表示する。右詰めで表示し、使っていない左の桁は淡い空欄にする。明示的な 0 にはほかの数字と同じ大きさとコントラストを使う。
- 各桁の発音が始まると、その枠を色と輪郭で強調する。発音が終わったら強調を戻す。「READ ALOUD」欄の英単語も桁の表示順とそろえる。
- ウサギの「DECIMAL」看板は、八進数の表示と同じフレームで更新する。下段の「IN THIS VIDEO」には「0–7」「10–77」「100–177」の三枚を置き、現在の桁数に対応する札を強調する。
- 各桁の数字と重みはそれぞれの行の中央に揃える。パネル内の読み上げ欄、繰り上がりの帯、下段の範囲札は、文字の見た目の中心と上下の余白を画像で確認する。

4. シナリオ

導入（約32秒）

ウサギが視聴者に声をかけ、八進数では 0 から 7 までの八つの数字を使うと紹介する。例として右二枠に 12₈ を表示し、左の空欄を残したまま「one」「two」の順で枠を強調する。ウサギが看板の 10 を見せて同じ数の十進表記だと伝える。続けて右端の重み 1 から、左へ 8、64 と順に視線を誘導する。「zero」の案内で導入を締め、最初のカウントへ移る。

一桁のカウント（0₈〜7₈）

右端の枠だけを使用し、0 から 7 を一語ずつ読む。7₈ を読み終えてから短い説明を挟み、7₈ + 1₈ = 10₈ の帯を表示する。カウント本体と看板は 7 のまま見せ、次のカウントの頭で 10₈ と十進数 8 に切り替える。新しい 8 の位と、右端に現れる 0 が見えるようにする。

二桁のカウント（10₈〜77₈）

右二枠を使って数字を読む。17₈ → 20₈ などの繰り上がりでは、前の数の読み上げ後に帯で変化を短く見せる。37₈（十進数 31）の後でウサギが伸びをする。看板の 31 は見える位置に置き、伸びを終えてから 40₈（十進数 32）に進む。77₈ では 77₈ + 1₈ = 100₈ を示して、右の二枠が 0 に戻り、64 の位に 1 が入るところを見せる。看板は次のカウントの頭で 63 から 64 に切り替える。

三桁のカウント（100₈〜177₈）

三枠を使い、途中や末尾の 0 も各桁の音として聞かせる。100₈ の後も 101₈、102₈ と一つずつ進める。177₈ で「one」「seven」「seven」と読み、看板に十進数 127 を表示する。

締め（約15秒）

177₈ と看板の 127 を掲げたまま、到達点を振り返る。ウサギが礼を伝えて手を振り、画面全体をクリーム色へフェードする。

5. 時間の設計

同じ数の各桁の発音の間は 0.90 秒。通常の数と数の間は前の数の発音が終わってから次の数の発音が始まるまで 2.00 秒。前作の構成を踏襲し、7₈ と 77₈ の後の説明に各 3 秒、37₈ の後のストレッチに 8 秒を追加する。予定尺は約 10 分 43 秒。カウントと効果の予定位置は同フォルダのタイムラインを参照する。
