2. 共通の音声・無音・mix指定

- BGMなし。風、砂の擦れ、static、環境音のSEなし。未使用の音声窓はdigital silence。
- 00:00.000-00:00.800は完全無音。SE、声、呼吸の追加も置かない。
- countのone / zero、説明台詞、SEは相互に重ねない。通常checkpointはvisual only。
- 既存採用one・dialogueの初期gainは1.0（0 dB）。新規zero・dialogueは既存profileの声量へ聴感を合わせる。数値だけを揃える自動AGCは採用しない。
- SE_PLACEとSE_FINISHの仮mix目標は、有効な発話のRMSより18 dB低いRMS。個々のgainは実測後に算出し、固定値で確定しない。SE_PLACE原本の仮peak -24 dBFSは生成時の振幅指定であり、mixの目標値とは別。
- 最終mixは約-16 LUFS、true peak -1 dBTP以下を検査目標とする。音量を実測済みとは扱わず、既存原本は加工して上書きしない。
- 短い単語clipへ一律の長いfadeを追加しない。音素を削らない。境界clickがある場合だけ、音素を傷めない無音側の2-5 ms処理を別候補として検査する。
- ambienceもBGMもないため、場面切替の音声crossfadeは不要。加工した派生音声は別hash・別版で管理する。

4. 通常カウント：全128状態の共通契約

読むのはdisplay_binaryの各桁に対応するzero / oneだけ。decimal_value、重み64 / 32 / 16 / 8 / 4 / 2 / 1、Everyday number caption、空欄は読まない。本文と順番はcount-lines.json / count-lines.tsvを正本とする。

各状態の相対時刻：
A. 0.000-0.120秒：prehold。主カウンタを次の正しいdisplay_binaryへ一括commitし、文字列を安定させる。carryの中間状態は主数字に出さない。
B. 0.120秒から：左端の有効桁の声を開始し、underlineをそのセルへ置く。
C. 単語間：0.055秒の仮silence。次の単語開始でunderlineを右へ進める。
D. 最後の語の後：0.180秒の仮posthold。数字列を保持する。

oneは既存採用clipの0.47583333333333333秒。zeroは未実測の仮0.52秒。単語尺、55 msの間、合計0.30秒のholdは別項目。制作時のhold調整案は状態合計0.12-0.35秒。最初の短い数だけ長く保持する場合も全体を再計算する。

発話中は数字列を変更しない。underline以外の指差し、口パク、eye rigを約束しない。通常はcanonical body。背景演出が継続しても声・数字・underlineを隠さない。

5. SE_PLACE：新しい桁の前の6回だけ

対象decimal_value：2 / 4 / 8 / 16 / 32 / 64。
未生成の計画SE。純音880 Hz、長さ0.080秒、attack 0.008秒、release 0.008秒、仮peak -24 dBFS。noise、風、砂、static、和音、残響tailなし。loopしない。

次の数のprehold 0.120秒内で、+0.000-0.010秒silence → +0.010-0.090秒SE_PLACE → +0.090-0.120秒silence。最初のbit声は+0.120秒開始。前の数の最終語へ重ねない。

新規本文はzero、I01-I08の8本、共通P07/P63のA new place is ready.、F05のSeven places, all ones!。SE_PLACEも未生成。既存clipは声・速度・本文・hashが一致した場合に再利用する。単語連結とフレーズ生成を比較するなら別候補で保存し、音声設計とtimelineを再計算する。

既存pipelineは0開始・二進数token照合をproduction-readyとして扱えない。実制作では次のgateを実装・確認する。
- sequence_index、decimal_value、display_binary、spoken_tokens、spoken_textを分けて保持する。
- expected token列をzero / oneのまま照合する。one zeroをtenへ読み替えない。先頭や内部のzeroを捨てない。
- zeroは独立単語の認識・音素・音響・聴取を確認し、文脈認識だけで採用しない。
- 既存clipのSHA256、profile、本文を照合し、現行v002を上書きしない。
- 表示・音声・underlineが全128状態で一致し、読む間に主カウンタが変化しないことを確認する。
- 全音声の実測尺からtimelineを作り直す。声とSEの非重複、冒頭0.8秒の無音、末尾の余白、mix peak、cream fade開始前の発話終了を確認する。

本資料は企画・台本まで。127までの範囲、最終尺、採用音声は実測・検収後に確定する。既存第1動画と既存採用音声は変更しない。
