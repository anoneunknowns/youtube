Num-Num Numbers — Hexadecimal Count
企画・シナリオ案

1. 動画の内容

しま模様のネコ「とら」と一緒に、十進数の 0 から 127 を十六進表記の 0₁₆ から 7F₁₆ まで一つずつ数える。全 128 件。とらが持つ「DECIMAL」の看板には同じ数の十進表記を表示する。既存の通常の姿と片手を上げる挨拶を場面に合わせて使う。

導入で hexadecimal と base sixteen という呼び方を紹介し、0〜9 と A〜F の十六個の記号を見せる。A、B、C、D、E、F は、それぞれ一つの桁に入り、十進数の 10、11、12、13、14、15 に対応する。カウントでは各桁を左から順に、数字の英語名または英語の文字名で読む。1A₁₆ は “one [0.90秒] A” で、A は文字名の /eɪ/。対応する十進数 26 は看板で確認できる。

2. 背景テーマ「Starry Observatory」

月明かりの天文台のテラスを舞台にする。画面左奥に小さな観測ドームと望遠鏡のシルエットを置き、遠景にはなだらかな丘を描く。空には星を散らし、シリーズ共通の絵本風の質感でまとめる。

左手前にとらと看板を置き、右の学習パネルの周囲は落ち着いた色にする。空の星や建物は数字と重なりにくい位置に配置する。画角は固定し、とらの表情やポーズと桁の強調で進行を見せる。

3. 共通画面

左にとらと十進数の看板、右にクリーム色の学習パネルを配置する。上に「Num-Num Numbers」「HEXADECIMAL COUNT」と範囲「0–7F IN BASE 16」を表示する。

パネル上部は「BASE 16」。主表示は二つの固定幅の枠で、桁の重みは左が 16、右が 1。右詰めで表示し、一桁の数では左の枠を空欄にする。10₁₆ の 0 は数字として明確に見せる。A〜F は大文字で統一する。

「READ ALOUD」欄には数字の英単語と大文字 A〜F を配置する。二桁の例は「one  A」。全十六種類の読みを共通のベースラインと均等な枠に収め、強調中も文字や背景の位置を固定する。発音中の桁と読み上げ欄を同時に強調し、発音が終わると通常表示へ戻す。

看板の値は主表示と同じフレームで更新する。下段の「IN THIS VIDEO」には「0–F」と「10–7F」の二枚の範囲札を置き、現在の桁数に対応する札を示す。

4. シナリオ

導入（58秒）

とらが片手を上げて挨拶し、十六進数の名前と十六個の記号を紹介する。0〜9 と A〜F を見せ、A = 10、B = 11、C = 12、D = 13、E = 14、F = 15 の対応表を順に強調する。声は文字名と十進値を一組ずつ伝える。

続いて 1A₁₆ と看板の 26 を同時に表示する。“one” と “A” の発音の間を 0.90 秒空け、左から右へ読む例を示す。右の 1 の位と左の 16 の位を示した後、0 の表示へ切り替える。左の空欄を読み飛ばすことを伝えて、カウントへ入る。

一桁のカウント（0₁₆〜F₁₆）

右の枠を使い、zero から nine まで数える。9 の次に A が現れ、文字名で A、B、C、D、E、F と続く。看板は 9、10、11、12、13、14、15 と進む。

F₁₆ を読み終えた後に短い説明を入れる。主表示 F と看板の 15 を保ち、比較帯に「F + 1 = 10（BASE 16）」を出す。左の 16 の位を示し、次の数の頭で主表示を 10₁₆、看板を 16 に更新する。“one” と “zero” を一桁ずつ読む。

二桁のカウント（10₁₆〜7F₁₆）

10、11 と進み、19 の後は 1A、1B、1C、1D、1E、1F と続く。1F の次は 20。右の桁が F のときに一つ足すと、右が 0 になり左の桁が一つ進む様子を、比較帯で示す。

3F₁₆（十進数 63）を読み終えた後で、位の値を確かめる場面を挟む。比較帯に「3 × 16 + 15 = 63」を表示し、左の16の位、右の1の位の順に示す。とらは通常の姿で看板の63を見せる。確認を終えると主表示を40₁₆、看板を64に切り替え、そのままカウントを再開する。7F₁₆ まで同じ速さで数え、最後は “seven” と文字名の “F” を読む。看板の値は 127。

締め（15秒）

7F₁₆ と看板の 127 を見せて到達点を振り返る。とらが視聴者に礼を伝え、片手を上げて挨拶する。最後の二秒で画面全体をクリーム色へフェードする。

5. 時間と音

二桁の発音の間は 0.90 秒。通常の数と数の間は、前の数の最後の発音が終わってから次の数の最初の発音が始まるまで 2.00 秒とする。F₁₆ の後には三秒の説明、3F₁₆ の後には八秒の位の確認を追加する。

カウント用の音声は 240 語、二桁内の間隔は 112 か所。予定尺は文字音声の仮の長さを含むタイムラインで算出し、収録後に実測値へ置き換える。冒頭は静かに始め、桁が増える 10₁₆ と締めに短い効果音を置く案とする。
